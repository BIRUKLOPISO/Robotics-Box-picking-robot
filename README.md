# Color-Sorting-Robot

A robotics simulation project where a robot **picks up boxes based on their color** from a rotating conveyor and **sorts them into their respective positions**. A graph displays information about the robot's sorting task.

## About

This project demonstrates automated color-based sorting in a simulated environment. Boxes move along a rotating conveyor, and the robot identifies each box's color, collects it, and places it in the correct destination. The task is visualized on a graph for monitoring and analysis.


## How It Works

1. Boxes move along a rotating conveyor toward the robot.
2. The robot scans each box and identifies its color.
3. Based on the detected color, the robot picks up the box.
4. The box is placed in its respective sorting position.
5. A graph updates to show information about the sorting task.

## Software Used

- **CoppeliaSim** – a powerful robotics simulator used for modeling, programming, and testing the robot's behavior in a virtual environment.

## Getting Started

1. Download and install CoppeliaSim (the free Educational version works fine).
2. Clone or download this repository.
3. Open the scene file (`4th.ttt`) in CoppeliaSim.
4. Press Play to start the simulation.
5. Watch the robot pick and sort boxes by color, and check the graph for task information.
